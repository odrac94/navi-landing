¿Qué es Navi Lyrics?

Navi Lyrics es una extensión gratuita para Chrome que muestra letras sincronizadas, estilo karaoke, en una ventana flotante Picture-in-Picture mientras escuchas Spotify, YouTube Music o Apple Music en el navegador. La ventana se queda encima de tus otras ventanas y apps, así que la letra sigue avanzando mientras trabajas, estudias o navegas.

Las letras vienen de LRCLIB, una base de datos abierta de letras. Navi resalta cada línea en tiempo real, traduce la letra a 12 idiomas y te deja cambiar el estilo de la ventana con temas de color y skins retro. No necesitas cuenta.

Preguntas frecuentes

¿Navi Lyrics funciona con Spotify?

add

Sí. Navi Lyrics funciona con el reproductor web de Spotify (open.spotify.com) y muestra la letra sincronizada en una ventana flotante. La app de escritorio de Spotify no es compatible, porque las extensiones de Chrome solo funcionan dentro del navegador.

¿Navi Lyrics funciona con YouTube Music?

add

Sí. Abre music.youtube.com en Chrome, reproduce una canción y Navi muestra la letra línea por línea en la ventana flotante.

¿Navi Lyrics funciona con Apple Music?

add

Sí. Desde la versión 1.6.0, Navi Lyrics es compatible con el reproductor web de Apple Music en music.apple.com.

¿La letra puede quedarse encima de otras apps?

add

Sí. Navi abre la letra en la ventana Document Picture-in-Picture de Chrome, que flota encima de tus otras ventanas, incluso fuera del navegador. Puedes moverla y cambiarle el tamaño donde quieras.

¿Qué navegadores son compatibles?

add

Chrome, Microsoft Edge y Brave actualizados. Opera funciona después de activar el flag opera://flags/#new-auto-pip-for-documents. Firefox todavía no es compatible.

¿Navi Lyrics puede traducir letras de canciones?

add

Sí. Presiona el botón de traducir y cada línea muestra su traducción debajo, en tiempo real. Puedes traducir a 12 idiomas: inglés, español, portugués, francés, alemán, italiano, ruso, japonés, coreano, chino, árabe e hindi.

¿De dónde salen las letras? ¿Y si están mal?

add

Las letras vienen de LRCLIB, una base de datos de letras gratuita y construida por la comunidad. Si una canción muestra la letra equivocada, presiona el botón de pulgar abajo y Navi cambia a la siguiente versión disponible.

¿Navi Lyrics es gratis? ¿Recopila mis datos?

add

Navi Lyrics es gratis y no necesita cuenta. No recopila datos personales: tu configuración y las letras en caché se guardan localmente en tu navegador.
